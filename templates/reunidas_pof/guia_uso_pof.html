{% elif seccion_activa == "reunidas" and form and not pof_solo_visualizacion %}

explore_nearby Cómo aprovechar esta pantalla

Completá la cabecera de la nueva POF y revisá la base inicial antes de confirmar.

collections_bookmark POFcalendar_month Añoapartment Nivel

collections_bookmark 1. Indicá año y nivel

  • Completá los dos campos del formulario.
  • Usá Crear POF para continuar.

folder 2. Revisá la base automática

  • Si existe una POF del año inmediatamente anterior para el mismo nivel, se tomará como base.
  • Se heredarán localizaciones, cargos y estados AFECTADO y DESAFECTADO.
  • La POF anterior no se modifica.
  • lightbulb_2 Tené en cuenta: la base se determina automáticamente; no se elige otra POF desde este formulario.

group 3. Confirmá el resultado

  • Si no existe una base anterior válida, la nueva POF comenzará vacía.
  • Usá Cancelar si no querés crearla.

collections_bookmark 1. Aplicá filtros

  • Elegí Año y Nivel.
  • Presioná Aplicar filtros o Limpiar filtros.

folder 2. Abrí una POF

  • Revisá año, nivel y última modificación.
  • Abrí el menú de acción de la fila y elegí VER DETALLE, AFECTAR CARGOS, ADMIN. CARGOS o EXPORTAR POF.

group 3. Elegí la acción

  • Usá ELIMINAR POF solo si necesitás quitar esa POF y la pantalla habilita la operación.
  • lightbulb_2 Tené en cuenta: el sistema verifica que no tenga actividad administrativa posterior ni sea base de otra POF.

explore_nearby Cómo aprovechar esta pantalla

Validá el Proyecto Especial, definí el origen de la localización y prepará la lista antes de guardar.

folder_special Proyectosearch_check_2 Padróngroup Cargos

collections_bookmark 1. Validá la cabecera

  • Seleccioná el Proyecto Especial POF.
  • Presioná Validar cabecera antes de continuar.

folder 2. Elegí el origen

  • Usá Buscar en padrón para localizar una oferta oficial.
  • Usá Ingreso manual controlado cuando corresponda a una referencia sin CUEANEXO.
  • lightbulb_2 Tené en cuenta: si la localización tiene CUEANEXO, la carga debe hacerse desde padrón.

  • En padrón, indicá CUE y Anexo y seleccioná la oferta.
  • En ingreso manual, completá la referencia solicitada. Si el CUOF tiene CUEANEXO, la pantalla indica que debe buscarse en padrón.

settings_account_box 4. Cargá los cargos

  • Buscá el CEIC, indicá cantidad y unidad: Cargo u Horas Cátedra.
  • Revisá puntos, total y observación y agregá el cargo a la lista.

search_check_2 5. Revisá y guardá

  • Comprobá la lista completa y presioná Guardar carga.
  • Confirmá el guardado cuando aparezca la confirmación.

collections_bookmark POFsearch_check_2 Padróngroup Cargos

collections_bookmark 1. Validá la cabecera

  • Seleccioná Año y Nivel.
  • Presioná Validar POF antes de buscar.

  • Indicá CUE y Anexo para consultar el padrón.

  • Elegí una o más ofertas del mismo CUEANEXO.

  • Seleccioná el cargo y revisá los puntos informados.
  • Indicá cantidad y unidad: Cargo u Horas Cátedra.
  • Revisá el Total calculado antes de agregar el cargo.

search_check_2 5. Armá la lista

  • Presioná Agregar cargo a la lista para incorporar cada cargo.
  • Si hace falta, completá una observación y revisá cantidad, puntos y total.

tab_recent 6. Revisá y guardá

  • Presioná Guardar carga.
  • Confirmá el guardado cuando aparezca la confirmación.

{% elif seccion_activa == "consultar" and not pof_solo_visualizacion %}

explore_nearby Cómo aprovechar esta pantalla

Usá los filtros para encontrar un cargo y abrí su gestión para revisar o actualizar los datos disponibles.

search_check_2 Buscarsettings_account_box Gestióncheck_box Estado

collections_bookmark 1. Aplicá filtros

  • Podés filtrar por año, nivel, CUEANEXO, CUOF, CEIC, estado y unidad.
  • Aplicá o limpiá los filtros según la consulta.

folder 2. Abrí Gestión de cargo

  • Revisá cabecera, CUEANEXO, CUOF y establecimiento.
  • Si corresponde, seleccioná las ofertas asociadas.

group 3. Modificá lo disponible

  • Podés modificar cantidad, unidad y observación.
  • CEIC, cargo, puntos y total se muestran como referencia.

settings_account_box 4. Afectá o desafectá

  • El control de Estado permite alternar entre AFECTAR y DESAFECTAR.
  • Al volver a AFECTADO, la cantidad debe ser un número entero mayor que cero.
  • Usá Guardar cambios para confirmar.
  • Eliminar cargo abre una confirmación antes de borrar definitivamente.
{% elif seccion_activa == "visualizacion_cargos" %}

explore_nearby Cómo aprovechar esta pantalla

Usá el visualizador para encontrar información, ajustar la vista y exportar la consulta.

search_check_2 Buscarsettings_account_box Filtroscloud_download Columnascloud_download Exportar

collections_bookmark 1. Buscá información

  • Elegí una columna buscable y escribí el valor en Buscar en esta columna.
  • Usá el botón de limpieza de búsqueda para quitar ese criterio.
    • {% if not es_proyecto_especial %}
  • En la vista POF también podés seleccionar el año.
    • {% endif %}

folder 2. Aplicá filtros

  • Usá Filtros y luego Agregar filtro para combinar criterios de localización, oferta, estado, cargo, cantidad, puntos o total.
  • Retirá un criterio desde sus chips o elegí Limpiar todos para ampliar la consulta.

group 3. Elegí columnas

  • En Columnas podés mostrar u ocultar información.
  • Usá Todas, Ocultar Todas o Por Defecto según la vista que necesites.

settings_account_box 4. Ordená resultados

  • Presioná el encabezado de una columna ordenable.
  • La paginación mantiene agrupados los cargos por CUE.

search_check_2 5. Usá modo compacto

  • Desde Columnas, activá Modo compacto para ver más información en menos espacio.

tab_recent 6. Exportá

  • Desde Exportar, elegí Exportar vista actual o Exportar todos los datos.
  • Las dos opciones generan un archivo Excel.
